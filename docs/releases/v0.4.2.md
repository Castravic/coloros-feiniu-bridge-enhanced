Date: 2026-10-19 (Asia/Shanghai). Based on v0.4.0, with Gallery 16.50.8 and
17.10.7 backup compatibility fixes, dependency-aware mobile-backup settings,
lifecycle-based temperature decisions and reproducible build entry points.

existing Android Debug certificate as the published v0.4.0 / v0.3.6 packages.
It is not the debug-variant APK. The existing certificate is retained for update
compatibility; no independent release key has been introduced in this release.

# v0.4.4 release validation

Date: 2026-11-25 (Asia/Shanghai). Version `0.4.4`, versionCode `19`.

## Behavior

- Eliminated Gallery cold-start main-thread DEX / DexKit scans (`onPackageReady` and `Application.attach`), skipped Gallery sub-processes, and consolidated initial discovery into a single-pass background scan (`FeiniuBridgeResolver`).
- Added persistent per-APK `StartupResolutionCache` (`StartupCachePolicy` Schema v2 XML-safe single-line format with synchronous `commit()` on background writes) storing resolved token decryptor class, `GwToken` prefix, `ColdStartSyncTargets`, and positive/negative scan flags.
- Added cross-version dynamic `ColdStartSyncLocator` + cache integration for local cold-start sync recovery (no longer limited to fixed version names), plus fast-path mappings for Gallery `17.10.41` (`feq$b`, `bzr`, and constructor-inlined `NasBackupConditionObserver` fallback hooks on `a(Z)` / `b()`).
- Confirmed on a real ColorOS 17 / Android 17 device running Gallery `17.10.41`: cold-start launch #1 writes v2 startup cache (`startup cache=write ok=true ...`), launch #2 hits all caches directly (`startup cache=hit`, `via=cache`, `source=cache`, `mobile data backup capability ready=true`) with zero background DEX/DexKit scan and `~10 ms` `Application.attach` overhead, and no screenshot display delay reproduced.
